# 溪间小筑 · Quiet Creek

基于 Three.js 的可交互林间溪谷场景。固定 **16:9 横屏**，提供四种光照、沿溪漫步、石桥和门廊机位。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址，通常为 http://127.0.0.1:5173/。也可以双击 `start.cmd`。如果该端口已经有本项目在运行，直接访问已有预览。

```powershell
npm run build
npm run preview
```

`dist/` 是可独立部署的静态构建产物。运行时所有模型、纹理和脚本均在本地，不依赖在线素材服务。

## 交互

- 拖动：环顾；滚轮：沿溪前后漫步；WASD：移动；Shift：加速。
- 午后 / 金色 / 蓝调 / 月夜：平滑切换光照与窗灯。
- 溪流 / 石桥 / 门廊：按距离和转身角度缓慢切换机位，至少 4.5 秒，常用机位之间约 6–11 秒；开始和结束平滑加减速，拖动或漫步可随时接管。自由漫步限定在河谷内；桥前与坡面有位置约束。
- 摄影：统一开关景深、辉光、色彩和镜头质感；景深可单独开关。H：隐藏或显示界面。
- 设置：光圈、对焦距离、质感强度、水速、波纹、风力、亮度、音量和渲染品质。
- 声音：点击后播放本地合成的水声、日间鸟鸣或夜间虫声。
- 全屏：保持 16:9；移动设备在浏览器支持时请求横屏锁定。
- 相机按钮：下载当前横屏场景的 PNG，照片不含控制界面。

窄窗口和竖屏手机保留完整 16:9 画面，不裁切或拉伸。竖屏标题位于画面上方，时段、机位、摄影和保存按钮利用画面下方留白；极小窗口可纵向滚动。手机横屏采用上下工具栏，常用按钮至少 44×44 CSS 像素。布局读取容器安全区并跟随可视高度变化，设置面板独立滚动，关闭按钮保持可见。


## 摄影效果

默认以金色时段进入溪流机位，使用 f/1.4、8 米对焦与 1.50× 摄影质感；“恢复初始”也使用这组参数。光圈可调 f/1.4–f/8，对焦可调 3–40 米；切换石桥和门廊时自动切换适合该机位的焦点，回到溪流时恢复 8 米对焦。关闭摄影会保留景深开关偏好，重新开启后恢复。

景深读取场景深度，将焦点前后分别处理；水面高亮微面在线性 HDR 中保留，再经圆形光圈采样形成散景。镜头采用薄透镜公式并做艺术化尺度补偿，并非真实相机的精确光学模拟。后处理包括克制的辉光、冷暖分色、边缘色差、暗角与细颗粒，最后统一进行 ACES 色调映射。

光照同步调整了日月位置、明暗比例和远景雾，草叶与树叶增加迎光透射感，天空补光保留背光木材和树皮的层次。精致是默认最高档，使用 4× MSAA（设备支持时）和 64 点半分辨率散景采样；两档品质均有 SMAA 边缘处理。抗锯齿独立于摄影开关，关闭摄影后仍保留 SMAA；关闭摄影会释放散景缓冲。水面微高光按像素覆盖范围过滤，以减少细碎闪烁。手动选择流畅模式会降低采样与分辨率，保留相同的光照和镜头控制。

四个时段分别组织光照与胶片色彩：午后以黄绿受光草尖衬托青透溪水；金色保留冷暗树荫，将暖光集中在林隙、草冠与水中反光；蓝调以薰衣草天光、暗青岸坡衬托暖窗；月夜降低环境照明，保留银蓝水光和木屋灯火。阴影色、亮部色、饱和度与对比度随时段平滑过渡，复用原有镜头处理，不增加后处理绘制。

溪水按视角分配反射与透射，并按水中光路长度吸收颜色；方向化短波与错落波峰打散倒影，保留局部 HDR 光点。23 块溪中主石采用不对称磨圆形体、共享的程序矿物纹理和随水线渐变的湿润色及粗糙度，贴石弧纹与分叉短尾流随日月光、天空色变化。主石和绕流保持实例化。没有新增第三方素材或依赖。

构图采用缓弯溪流、非对称树群和右侧远屋；木屋及石桥整体向上游后移 30 米，与初始溪流机位的纵向距离由 56 米增至 86 米，中段溪道增加缓弯和延续的石岸，让建筑隐在远处林间。门廊、石桥机位、窗灯、桥下水面阴影和漫步范围随建筑同步定位。金色以左侧林隙逆光、右岸局部暖光和桃金倒影组织画面，蓝调采用蓝紫天光、深色岸坡和暖窗焦点。水面反射、吸收色与高光随时段平滑变化，短波纹打散倒影，河中主石疏密分组，屋前保留连续水面。

## 工程内容

| 文件 | 内容 |
| --- | --- |
| `src/main.js` | 场景组装、相机、交互和渲染循环 |
| `src/water.js` | 平面反射与折射、动态法线、日月高光、水下光斑、石头尾流 |
| `src/landscape.js` | 河床、护岸、远丘、草叶、分枝树与灌木实例化 |
| `src/atmosphere.js` | 云、星空、日月光、雾和四种光照预设 |
| `src/lens.js` | HDR、前后景散景、辉光、镜头质感和色调映射 |
| `src/ui.js` / `src/style.css` | 固定横屏的场景界面 |
| `src/audio.js` | Web Audio 合成自然环境声 |
| `public/models/cottage.glb` | Blender 导出的木屋与贯通石拱隧道，贴图内嵌 |
| `assets/cottage.blend` | 可编辑的 Blender 源工程 |
| `scripts/build_cottage.py` | 可重复生成 Blender 模型的脚本 |

重新生成模型（本机路径）：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python scripts/build_cottage.py
```

只有木屋与石拱桥使用 Blender 模型，其余场景由代码生成。木屋 GLB 约 1.58 MB（初版 10.22 MB，第一轮精简后 3.67 MB），压缩保存的可编辑 Blender 源文件约 1.07 MB（初版 6.66 MB）；脚本、Blender 源文件与 GLB 同步维护。

模型保留窗洞、窗扇、梁架、椽子、烟囱和门廊花箱。薄木板、屋瓦与铁件省去细小倒角，较大构件使用单段倒角，三角面从 186,204 降至 52,316，保持 24 个材质网格。木纹、石纹分别共享一张颜色贴图，以材质颜色系数保留各构件的色差；连同两张法线贴图共 4 张，均为过滤后的 256×256 内嵌 PNG。石拱内部连续砌体遮挡砖缝漏光，通道保持贯通。

生成脚本使用 Blender 5.2 的 `EXT_meshopt_compression` 导出，并将浮点过滤精度设为 20 位。加载端复用现有 Three.js 附带的 Meshopt 解码器，随站点脚本打包，不请求 CDN，也不新增 npm 依赖。第二轮只共享贴图、压缩数据，保持面数与网格分组；解码对比测得顶点最大单轴偏差约 0.03 毫米，颜色贴图每通道平均偏差小于 1/255。当前完整生产包约 3.20 MB。

植被和地形由代码生成：70 棵树、13.2 万根成丛草叶、约 9.5 万叶簇卡片和 192 朵带茎叶的花。弯曲分叉树干采用封闭交叠接头，避免透天缝；石岸使用厚薄、角度与层高有变化的磨圆块石，溪中主石单独使用更圆润的水磨卵石几何并锚定河床。主要景观为 10 个实例化或地形绘制批次。精致模式按设备像素比渲染，上限由 1.5 提高至 3；网站限制为 400 万总像素。流畅模式像素比最高 0.85，各档位均保持用户选择，不根据帧率自动降档。提高分辨率会增加 GPU 开销，真机帧率与发热需实测。

## 场景实现

场景包括溪流反射与折射、木屋与石拱结构、风动植物及昼夜氛围。木屋与石拱桥使用 Blender 建模，其余地形与植被由代码生成；水声、鸟鸣和虫声采用 Web Audio 程序合成。
